# 角色设定 · 《白雪公主与七个小矮人：溪谷救援》

> 造型为本片原创的童话诠释，只保留公版童话角色的识别要素（黑短发、红发饰、蓝上衣、黄长裙、七位矮人的性格名）。
> 全部角色在 `src/characters/specs.ts` 中以参数定义，由 `src/characters/build.ts` 程序化生成；修改造型只需改参数。

## 统一规格

| 项目 | 规格 |
|---|---|
| 单位 | 1 单位 = 1 米 |
| 白雪身高 | 1.66 m，正常成人比例（头身比约 1:7） |
| 矮人身高 | 1.04–1.20 m，头身比约 1:3.6–1:4，躯干长、四肢短、手掌宽 |
| 骨骼 | hips → spine → chest → neck → head；肩 → 上臂 → 前臂 → 手(4 指 × 2 节 + 拇指)；髋 → 大腿 → 小腿 → 脚 |
| 解算 | 双骨 IK（手、脚）、按路程落脚的步态（防滑步）、头/眼注视目标 |
| 面部控制 | blink、lidOpen、browRaise、browFurrow、browAngry、smile、mouthOpen、blush、noseWrinkle、jaw |

## 白雪公主 Snow White

- **剪影**：乌黑卷曲短发（及颌）、头顶红色蝴蝶结发饰、白色立领、蓝色紧身上衣配红色开衩泡泡袖、黄色及地长裙。
- **面容**：瓜子脸、浅肤色带暖调红晕、深棕虹膜、上眼睑睫毛线、红唇；眼睛有角膜高光。
- **性格动作**：先观察再行动；步幅适中、肩背挺直；危险时重心降低、双臂外展；抱小鹿时下巴贴近鹿头安抚。
- **服装物理**：裙摆有滞后摆动（随髋部速度/加速度延迟），膝盖向前时顶起前片；入溪后裙边湿痕上升，湿区颜色更深、粗糙度更低（更反光）。

## 小鹿 Fawn

- 红棕被毛带白色斑点、大耳朵、黑湿鼻头、细长四肢；肩高约 0.55 m，可被白雪抱起。
- 行为：发抖、后退、耳朵转动、抬头鸣叫、转头看向白雪、碰触害羞鬼的手、嗅苹果。

## 道具

苹果篮（白雪）、工具小推车（锯、镐、灯笼、工具袋，车底藏备用绳索）、倒木（直径 0.46 m、长 7.8 m）、溪中岩石、锚定大树（外露树根）、远处亮暖光的木屋。
