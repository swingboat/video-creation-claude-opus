## 四、迭代修正记录（实际发现并修复）

1. 三处粒子着色器 `#include` 需独占一行 → 修复，消除编译报错。
2. 水面全屏“白斑”实为雾天**亮天空反射**被波法线打碎 → 降低菲涅尔/天空反射与法线强度、加深水体色，水面转为自然深绿带局部泡沫。
3. 白雪在倒木段曾沉到河床高度、手臂因绝对高度上举 → 增加**倒木表面高度覆盖**与落脚；将休息臂/摆臂高度改为相对根节点。
4. 白雪头顶头发穿刺、鼻子过大 → 增加实心发帽 + 整齐刘海、缩小“小鼻”造型。
5. 小鹿被抱时过大且竖立 → 整体缩放 0.72，抱姿下移并倾斜、四肢收拢。
6. 结尾镜头推进过近致白雪蓝衣挡镜、只见矮人后脑 → 重构镜头 16 为溪侧回看岸上群像。
7. 苹果递交时白雪与糊涂蛋相距 4.7m → 结尾让白雪走到糊涂蛋身旁再递；小鹿落点移近害羞鬼以成立“轻碰手”。

## 五、已知限制

- 画面为**童话风格化 CG**（程序生成），非照片级真人质感；在近景与侧逆光下角色辨识度与表演清晰，但皮肤/布料的次表面与织物细节为近似。
- 远景树木与水面在浓雾/逆光下偏柔，属刻意的空气层次；如需更锐利可在 `scene.ts` 降低 `FogExp2.density` 与泛光阈值。
- 若要进一步提升人物影视级质感，建议后续引入高质量带骨骼 glTF 角色与表情/动作素材（见 [03-素材清单.md](03-素材清单.md) 的补齐方案），并替换 `buildCharacter` 为 glTF 加载 + 重定向；时间轴与镜头系统无需改动。

# v2 重制（2026-10-20）

## 用户反馈
1. 画面效果远差于 ocean-shallows；2. 成片几百 MB。

## 体积问题原因与修复
- 原因：调色 shader 中每帧变化的全屏噪点颗粒 + CRF 17，使编码器无法帧间压缩（原片约 39 Mbps / 430 MB）。
- 修复：改为静态细微抖动；`render.mjs` 默认 CRF 23、x264 slow、yuv420p、AAC 192k。
- 结果：90 秒 1080p 成片 **82 MB（约 7 Mbps）**。

## 画面升级
- 人物：程序化几何体 → MPFB/MakeHuman CC0 写实人体（皮肤贴图、真实眼睛、睫毛、头发、42 个 ARKit 表情形变、53 骨骼含手指），见 [03-素材清单.md](03-素材清单.md)。
- 小鹿：Blender 建模带骨骼 GLB。
- 环境：Poly Haven CC0 HDRI 光照、扫描地面/河床/树皮/岩石纹理、扫描蕨类与灌木等实例化植被。
