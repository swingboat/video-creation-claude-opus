# 分镜与空间设计

## 空间布局（俯视，单位米，y 轴向上）

```
            远岸 (z < -3.3)            F(-0.4,-3.9) 倒木远端
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~|~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  溪流 → 流向 +x
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~|~~ R(1.15,-0.35) 小鹿岩石 ~~~~~
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~|~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
            近岸 (z > 3.3)      绳结 K ●  N(0.6,3.9) 倒木近端      害羞鬼 B(2.0,3.6)
   锚树 T(-6.6,4.3) ●━━━━━━━━━━━━━━━━━━●  ← 绳索拉力方向 (−x，逆水流)
      瞌睡虫  糊涂蛋  博士  喷嚏精  开心果  爱生气
   小路 z≈6.2：小推车 C(3.6,6.6)；篮子放在 (1.5,4.6)
   木屋位于上游近岸 (-19,0,15)，结尾众人沿小路向 −x 走回木屋
```

- 水流方向固定为 **+x**；镜头轴线保持在近岸一侧（z > 0），因此画面中水流始终“从左向右”或“由远及近”，不越轴。
- 倒木被水流推向 +x（下游）；绳索从倒木近端系往上游锚树，七人沿绳向 −x 拉，受力方向清楚。

## 光照曲线

- 0–55 s：雨后冷调（色温约 7000 K），太阳被云遮挡，天空光为主。
- 55–74 s：云层开始散开，逆光逐步加强。
- 74–90 s：金色夕照（约 3500 K），侧逆光勾出头发与胡须轮廓，木屋窗户暖光。
