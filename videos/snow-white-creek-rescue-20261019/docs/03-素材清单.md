# 素材清单（Asset Manifest）· v2

v2 用真实的 CC0 / 公开授权素材替换了 v1 的程序化几何人物与贴图。

## 人物（8 个主角）

由 **MPFB 2.0.18**（MakeHuman for Blender，GPL-3.0 插件，仅用于本机生成，不随片分发代码）在 Blender 5.2 中无界面批量生成，脚本：[build_characters.py](../assets-src/blender/build_characters.py)。

| 来源 | 内容 | 授权 |
|---|---|---|
| MakeHuman system assets | 基础人体、眼睛、眉毛、睫毛、牙齿、头发（bob02/short02/03/04）、服装网格（female_elegantsuit01、male_casualsuit01、shoes01/03） | CC0 |
| skins01 / skins02 | 写实皮肤贴图 | CC0 |
| system_hair_materials01 | 头发材质 | CC0 |
| faceunits01 | ARKit 表情单元（导出 42 个：眨眼、眉、颌、笑、皱鼻、视线等） | CC0 |

脚本额外完成：脸型/鼻/眉/耳的目标形变（七矮人各不相同）、侏儒比例（缩腿缩臂放大头后重设绑定姿势）、习惯表情烘焙（爱生气皱眉、开心果笑、瞌睡虫垂眼……）、童话服装（白雪泡泡袖/高领/黄长裙/红发结；矮人外衣下摆、腰带、尖帽）、胡须发卡（按脸部特征点生长并随表情形变）、博士圆眼镜、喷嚏精红鼻、害羞鬼脸红。导出带 53 骨骼（含手指）的 GLB：`public/models/<id>.glb`。素材包原件在 `assets-src/vendor/`。

## 小鹿

[build_fawn.py](../assets-src/blender/build_fawn.py) 在 Blender 中建模（皮肤修改器 + 细分 + 23 根骨骼自动权重 + 顶点色毛色与白斑），导出 `public/models/fawn.glb`。原创。

## 环境（Poly Haven，CC0）

由 [fetch-assets.mjs](../scripts/fetch-assets.mjs) 下载，完整清单（作者、链接、分辨率）见 [assets-polyhaven.json](./assets-polyhaven.json)：

- HDRI：monbachtal_riverbank（雨后冷光）、sunset_forest（夕照）——基于图像的光照与反射
- 扫描纹理：forest_leaves_02（落叶地面）、river_small_rocks（河床）、mossy_rock、bark_brown_02（倒木/树干），以及服装布料细节 rough_linen / velour_velvet / wool_boucle / cotton_jersey / brown_leather
- 扫描模型：蕨类、荨麻、草、白屈菜、长春花、蒲公英、灌木、苔藓岩、巨石、树根群、树桩、枯木、树皮碎屑、枯枝、苹果、斧、锯、灯笼、木桶
- fir/pine 原模型超过 1 GB，已生成 LOD（`public/assets/models/*_lod.glb`，当前未启用，原件在 `.cache/heavy/`）
