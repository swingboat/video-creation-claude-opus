# 0b · 剧情、界面、音频、主循环

## 12-story.js — 状态机

`M.story = {step:0, matches:5, minutes:0 /*自23:00起*/, cold:0.25, locked:false, stations:[...]}`

- 站点对象：`{id, pos:{x,z}, radius:2.2, label, hint, run()}`。`step` 指向当前要去的站点（0..4）。
- 每帧：女孩距当前站点 < radius 且未锁定 → `M.ui.action('划亮第 N 根火柴')`（N 用中文数字），否则隐藏。
  按钮 / 空格键 → `strikeAt(station)`：锁定 → 女孩转向站点焦点 → `girl.play('strike')` → 火焰 → 站点演出 `run()` →
  字幕 → `matches--`、`minutes += 12`（第 5 根后到 60）→ 解锁、`step++`、更新提示。
- **寒冷值** cold：基础每秒 +0.006；`warm.at(girl)` 每秒 -0.08*warm；火柴燃着时 -0.05/s；限 [0.05,1]。
  cold ≥ 0.85：提示「好冷……到有光的地方去。」不惩罚；用于 `M.post.uniforms.uCold`、女孩发抖、呼白气。
- 时钟：`23:MM`，60 后显示 `00:00`；划火柴时数字滚动动画。

### 各站演出（时长约 4–7 s，镜头接管）

1. 炉门由暗变橙红（emissive 0→2.5），炉口出火焰粒子 + 烟管冒烟；常驻 PointLight（池）#ff8a3a 强度 3；`warm.add` r=4.5 power=1；光斑。
2. 镜头转向橱窗；窗内桌上道具从 scale 0 弹出（烤鹅、面包篮、两支蜡烛）；门打开（门板绕铰链转 80°）→ 白鹅 `appear` → `follow`。
3. 镜头拉远仰视大树；`candles.lightUp(2.5s)` → 树顶星亮 → 1.5 s 后 `riseToStars` → 天空中最亮那颗 `shootingStar` 落到 (4,-61.5) 留光柱。
   之后圣诞树保持常亮（作为暖源 r=6）。
4. 光柱中 `granny.show(2.5s)`；女孩 `look(granny)`；奶奶 `reach`。
5. 两人 `hug`；镜头缓慢环绕升高；屏幕渐白 + `audio.bells(12 下)`；同时 `uDawn` 0→1（8 s）：
   天空变晨、雾变亮、窗灯熄灭、所有路灯光斑淡出；雪变小；镜头最终俯瞰运河；→ `M.ui.ending()`。

## 13-audio.js — WebAudio 全合成（首次点击开场按钮时 `init()`）

- 主总线 → 压缩器 → destination；`setMuted(b)` 渐变 0.4 s。
- **风**：白噪声 → 带通（300–900 Hz，LFO 慢扫）→ 增益 0.08，持续；寒冷值越高风越大。
- **八音盒音乐**：公有领域旋律《平安夜》（Gruber 1818），音符表 [midi, beats]，3/4 拍 72 bpm；
  音色：两个正弦（基频 + 4 倍频，快速衰减 1.8 s）+ 轻混响（卷积冲激用噪声指数衰减生成 2.5 s）；
  每段结束停 4 s 再循环。站点 5 后改大调高八度轻快版本一次。
- **脚步**：踩雪咔吱 = 短噪声 burst（高通 1 kHz，40 ms，随机音高），左右交替轻微 pan。
- **划火柴**：噪声刮擦 120 ms（带通 2–4 kHz 下扫）+ "噗"（低通噪声 200 ms）。
- **火焰**：持续低通噪声 + 随机噼啪（短脉冲）；`flame(on)`。
- **白鹅**：`honk()` 锯齿 + 共振峰带通，快速滑音两声。
- **钟声**：`bells(n)` 每 1.6 s 一下：加性合成非谐泛音（1, 2.0, 2.4, 3.0, 4.2, 5.4 倍）指数衰减 4 s，基频 196 Hz；
- **魔法闪光**：`chime()` 上行琶音（五声音阶）铃音，用于站点演出。

## 14-ui-main.js

- DOM（在 01 中写好）：`#intro`（系列小字「童话补完计划 · 第一夜」、大标题「新年夜的火柴」、副标题「这一回，火光里的一切都会留下来。」、按钮「点亮第一根火柴」、操作说明）、
  `#hud`：左上 `#matches`（5 根火柴 SVG 小图标，用掉的变灰）、顶部中 `#clock`、右上 `#mute`(♪)；
  底部 `#hint`；中下 `#caption`（小标题 + 两行，淡入 0.8 s 停留 5 s 淡出）；`#action` 橙色胶囊按钮；
  `#ending`（「新年快乐」+ 一段短文 + 「再来一次」按钮 → location.reload()）。
- 开场：按钮点击 → `audio.init()` → intro 淡出 → 镜头从高空俯冲到女孩（3 s）→ 显示开场提示。
- 主循环：`requestAnimationFrame`；dt 上限 0.05；依次调用 onFrame 列表 → `M.post.render()`。
- 自适应质量：1 s 平均 FPS < 40 降 pixelRatio（最低 0.6×）、关阴影软化、减雪；> 57 持续 3 s 升。
- resize：更新相机 aspect、renderer、post RT。
- 快捷键：空格 = 划火柴（可用时），M = 静音。
- 隐藏调试：URL `?debug` 时 `window.M` 暴露 + `M.debug.jump(step)` 直接跳站点。
