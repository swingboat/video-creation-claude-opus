# 0f · 镜头与演出（精致化第一轮）

目标：每个站点的高光都"拍得到"；镜头不被遮挡；字幕与画面互不打架；结局回到人物身上。

## 1. 走位（10-control）
- `M.control.goto(x, z) → Promise`：剧情锁定时也能驱动女孩走到指定点（复用寻路/碰撞/走路动画），
  到达（<0.1 m）、卡住 0.6 s 或超时 4 s 时 resolve。键盘、点击在锁定时仍然无效。
- 每个站点新增 `mark`（站位）和 `face`（朝向点）。划火柴前先 `goto(mark)` 再转身，构图因此稳定。

## 2. 机位（12-story）
镜头约定：相机 = target + (sinYaw·cosPitch, sinPitch, cosYaw·cosPitch)·dist；yaw=0 在南、π/2 在东。
`shots` 为序列：`{ at: 秒, target, dist, yaw, pitch, rate }`，由 `S.shoot(list)` 按时间依次 `cam.focus`。
数值为初值，浏览器里逐站调到：主体在三分线、目标物完整入画、两张脸可见。
| 站 | mark | 构图意图 |
|---|---|---|
| 1 炉亭 | 炉门东南侧 (0.5, 10.0) | 东北侧 3/4 机位，炉门火光在画左，女孩侧脸在画右；点火后缓慢推近 |
| 2 面包房 | 橱窗南侧 (-1.6, -10.2) | 斜对立面，橱窗完整、女孩在画左侧脸；开门时摇向门口白鹅 |
| 3 圣诞树 | 树南偏东 (5.4, -48.6) | 低机位广角，整棵树+星入画、星不碰时钟；烛光升空时仰拍；流星落地时摇向台阶 |
| 4 台阶 | (4.0, -60.0) | 先过肩（女孩背影在前景、奶奶正脸被光照亮），再侧面双人镜头 |
| 5 拥抱 | 同上→走近奶奶 | 侧面中近景，慢推 3.6→2.8 m，停 3 s |

## 3. 结局（新文件 12e-ending.js，覆盖 `S.ending`）
1. 拥抱特写保持，钟声前 3 下；
2. 镜头沿台阶后退上升，女孩/奶奶/白鹅在画面下方剪影，教堂与烟花在上方（9 发烟花）；
3. 天亮 10 s：镜头回落到台阶前 3/4 中景，三者在晨光里（奶奶牵手姿势 `hold`，鹅坐下）；
4. 结局卡：遮罩改为上浓下淡，文字上移，人物在下半屏可见。

## 4. 遮挡处理（新文件 12d-camfx.js）
- 遍历场景所有内置材质（跳过女孩、奶奶、白鹅、ShaderMaterial），`onBeforeCompile` 链式注入：
  - 片元世界坐标 `vNfW`、视空间深度 `vNfD`；
  - **近相机淡出**：深度 < 1.4 m 全隐，1.4–2.6 m 抖动渐隐；
  - **视线圆柱淡出**：到「相机→焦点」线段距离 < 0.55 m 且位于焦点前方 0.8 m 以外的片元抖动隐藏；
  - 只作用于 y > 0.12 的片元（不挖地面与地面积雪）。
  - 抖动用交错梯度噪声；`customProgramCacheKey` 叠加原 key + `|nf`，避免程序缓存串用。
- 统一 uniforms：`uNfCam`、`uNfTgt`（每帧取相机与 `M.cam.target`）。
- 引路光（12b）：距相机 < 2.5 m 时淡出。

## 5. 电影化界面（01、14）
- 剧情锁定时上下黑边（各 8vh）滑入，解锁时滑出；HUD 提示与按钮隐藏。
- 字幕移到下方黑边上缘：标题小字 + 两行逐行淡入（第二行延迟 0.6 s），底部柔和暗渐变衬底；显示 6.5 s。
- 时钟在黑边出现时下移到黑边内，避免压画面。

## 6. 验收
- 五站逐个截图：目标物与人物同框、无遮挡、字幕不压主体；结局三张（拥抱、烟花、晨光）都看得到人物。
- 控制台 0 错误；帧率不低于原来的 90%。
