# 0c · 打磨：冷杉与小女孩

## A. 冷杉生成器 `06b-firgen.js`（07-props 之前执行）

- `M.firgen.tree(x, z, h, opts)`：只登记实例，返回 `{tips: Vector3[]}`（枝梢位置，供圣诞树放蜡烛）；
  `M.firgen.flush()`：在 07-props 末尾调用，一次性生成 InstancedMesh。
- **枝条卡片几何**：PlaneGeometry 长 1（沿 +X，从树干到枝梢）× 宽 0.62，长向 5 段、宽向 2 段；
  中脉抬高 0.08（V 形折起，侧看有厚度），枝梢下垂 `y -= 0.18*x²`；alphaTest 0.45，双面。
- **针叶贴图**（Canvas 256×128，透明底）：棕色中脉 + 两侧斜向短针叶（深浅 4 种绿，越靠梢越短）
  + 3–4 条侧枝；靠树干 10% 稀疏。**雪贴图**：沿中脉上方的不规则白色团块。
- **雪卡片**：同几何，实例矩阵上移 0.035、缩 0.9，只覆盖 60% 枝条（上半层更多）。
- **排布**：从 y=0.18h 到 h 共 `round(h*2.4)` 轮，每轮 6–10 枝（大树 9–12），轮间随机偏转；
  `R(y) = Rb * (1 - t)^0.85`（t 为相对高度），Rb = 0.33h；枝长 = R(y)·(0.85~1.1)；
  下垂角 0.25 + 0.35·(1-t)；每轮之间插一圈短枝填空（长 0.6×）。
- **颜色**：instanceColor，越靠下、越靠里越暗（0.55–1.0），带 ±8% 随机。
- 树心一根细长暗绿锥体填补空隙（半径 0.12h），树顶 3 片竖直小枝成尖。
- 阴影：`customDepthMaterial = MeshDepthMaterial({depthPacking: RGBADepthPacking, map, alphaTest})`，阴影跟针叶形状一致。
- 圣诞树：h=9.5，Rb=3.0；蜡烛取 140 个枝梢（均匀抽样，y>1），位置为枝梢上方 0.06。

## B. 小女孩外观 `07c-girl-look.js` + 修改 `08-girl.js`

1. **脸部贴图**：Canvas 512²，透明底；画大眼睛（深棕虹膜 + 黑瞳 + 2 个高光 + 上眼线与 3 根睫毛）、
   细眉、腮红（径向渐变）、小鼻尖阴影、微笑小嘴。另画一张闭眼版（弧线）。
   贴在头球前方一片球面（phi 宽 1.9、theta 0.3π–0.72π，半径 ×1.004），透明、depthWrite=false。
   每 3–5 秒眨眼一次（切 map 0.12 s）。删除原来的球体眼睛、高光、腮红圆片。
2. **边缘光**：女孩所有材质改为独立材质，`onBeforeCompile` 注入
   `rim = pow(1 - max(dot(normal, normalize(vViewPosition)),0), 3)`，
   `totalEmissiveRadiance += rimColor * rim * k`；rimColor 冷蓝（月光），火柴燃着时混入暖橙（`M.girlLook.rimWarm` uniform）。
3. **布料贴图**：头巾 = 红色针织纹（竖向罗纹 + 噪点）；披肩 = 灰蓝格纹；裙子保持补丁贴图，加缝线。
4. **二级动作**：头巾后方两条飘带（细长 Box，链式 2 节），随速度后摆 + 正弦摆动；
   裙摆随走路前后、左右轻摆；两侧发缕轻晃。
5. **手**：改成略扁的手掌 + 小拇指球，左右对称。
