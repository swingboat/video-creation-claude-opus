# 0i · 声音、女孩的眼睛、白鹅（精致化第四轮）

## 1. 声音（13-audio）
总线结构：`music → musicLP（低通）→ musicG → master`；`sfx → master`；`amb → master`；混响送出各自独立。
- **冷暖滤波**：音乐低通截止频率 = 900 + 7000 × 暖度（暖度 = 1 − 寒冷值，天亮时为 1），越冷越闷，烤火时变亮。
- **剧情闪避**：`A.duck(k, t)` 让音乐与风声在剧情高光时压低（站点划火柴时 0.45，结局钟声时 0.15）。
- **雪地脚步**：每步 = 3–5 个间隔 6–14 ms 的高通短噪声颗粒（"嘎吱"）+ 一个低频闷响；速度越慢颗粒越少。
- **水声**：靠近运河（x > 4）时，带通噪声做低频起伏的拍岸声，音量随距离衰减。
- **暖色和弦 `A.pad(chord, dur)`**：4 个略微失谐的三角波 + 慢起慢落（1.5 s / 4 s），走混响。
  用在：奶奶出现（Fmaj7）、拥抱（Cmaj9）、天亮（C → G/B → Am → F 缓慢四和弦）。
- **结局**：钟声前停掉夜间八音盒（`A.music(null)`），天亮后再奏大调版。
- **其他**：页面切到后台时 `ctx.suspend()`，回来 `resume()`；`A.level()` 返回当前总线 RMS（仅用于测试）。

## 2. 女孩的眼睛（07c、08）
脸部贴片拆成三层（同一套球面贴片，半径依次 ×1.004 / 1.006 / 1.008，`renderOrder` 递增）：
1. **底层**：眉、腮红、鼻影、嘴（无眼睛）；
2. **眼珠层**：虹膜 + 瞳孔 + 两个高光，透明底；通过 `map.offset` 平移实现看向（±0.028 / ±0.02）；
3. **眼睑层**：上眼线 + 睫毛；闭眼时切换为闭眼弧线并隐藏眼珠层。
- **视线**：有 `look` 目标时看目标；镜头距离 < 4.5 m 时看向镜头；否则朝前。每 0.8–2.5 s 一次微小扫视。
  头部局部坐标里算方位角/仰角，换算成偏移，带阻尼。
- **眨眼**：保持原节奏；剧情中看向奶奶时眨眼间隔加长（凝视感）。
- 三层都关闭阴影投射；底层保留原来的弱自发光，眼珠层自发光略高，让高光更亮。

## 3. 白鹅（09）
接口与动画不变（`gBody / wings / neck / gHead / gLegs`）。
- 身体：泪滴形 lathe（胸圆、尾部上翘收尖），尾部一小簇 3 片羽毛（扁椭球扇形）。
- 翅膀：每侧由 1 片主翼（扁椭球）+ 3 片后掠飞羽叠成，羽尖略灰。
- 脖子：每节换成两端重叠的胶囊，S 形更顺；头部略小、额头更圆。
- 喙：上下两片 + 喙根橙色小瘤；眼睛加白色高光点。
- 脚：扁平三角蹼（ShapeGeometry），三根趾线。
- 材质：白色略带暖灰、粗糙度 0.8；保留跟随光晕。

## 4. 验收
- 声音：总线 RMS 在走路、划火柴、结局时都有信号且不削波（峰值 < 0.95）；控制台无报错。
- 近景：女孩看向镜头 / 看向奶奶两张对比；白鹅侧面与正面近景。
- 全流程跑通，控制台 0 错误。
