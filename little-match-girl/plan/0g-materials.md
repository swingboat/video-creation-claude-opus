# 0g · 场景材质与细节（精致化第二轮）

目标：消除"马赛克石板、纸片雪、平板立面、公寓式教堂、方块船"这五个最显眼的粗糙点。
原则：只改贴图生成和几何细节，不改布局、坐标、碰撞与剧情；新增几何全部走 `M.batch`（合并后 draw call 不增加）。

## 1. 贴图（02-core）
- **石板 cobble**：每块石头用径向渐变画出"中间亮、边缘暗"的圆润感（假浮雕），颜色在冷灰/暖褐之间更柔和；
  缝隙更深更窄；加入少量碎石与磨损高光。保持 1024² 与原 key。
- **灰泥 plaster**：去掉方块污渍；改为逐像素 fbm 低频明暗 + 细颗粒 + 竖向雨水痕（从顶部往下淡出）+ 底部返潮暗带。
- **木板 planks**（新）：横向船板，每条带深色接缝、木纹与少量钉点，供船体使用。

## 2. 地面（04）
- `bumpMap = cobble`、`bumpScale ≈ 0.035`：石块浮起、缝隙下陷（雪区自动被雪色覆盖）。
- 宏观变化打破平铺：两层低频 fbm 调整明暗（±12%）与冷暖，远处不再呈规则网格。
- 积雪边缘：`smoothstep` 带宽从 0.08 增到 0.16，并用高频噪声扰动边界；边缘内侧加一圈略亮的"雪壳"，外侧石板加一圈湿润深色；
  雪面加入随视角闪烁的冰晶亮点（hash 阈值，强度很低）。

## 3. 立面（05a）
- **楼层腰线**：每层窗户上方一条细凸线（墙色加深 15%），房屋更有体量。
- **窗楣**：每扇窗上方一个小檐（宽 1.02、高 0.12、凸 0.12，带 2 cm 积雪）。
- **百叶窗**：约 35% 的房子给窗户加左右木百叶（深绿 / 深红 / 深蓝三选一）。
- **窗户变化**：亮窗贴图改为 2×2 图集（窗帘半掩、窗台盆栽、吊灯、纯暖光），按实例属性 `aVar` 选格；
  暗窗加一点月光反射斜纹。
- 新增选项 `o.windows === false` 时不生成窗户与门（教堂用）。

## 4. 教堂（05b）
- 关闭普通窗户；正立面两侧各一扇高拱形彩窗（发光，拱形 alpha 贴图），侧墙各 3 扇。
- 玫瑰窗重画：外圈 16 瓣 + 内圈 8 瓣 + 铅条描边 + 中心，亮度降到 1.4，看起来是彩色玻璃而不是饼图。
- 正立面 4 根壁柱 + 门楣三角，台阶两侧石座。
- 钟楼：方塔顶加钟楼层（四面拱形开口 + 表盘），塔尖改八棱锥、底部收腰，顶端金球十字。

## 5. 木船（06）
- 船体用 `planks` 贴图，去掉 flatShading；舷边加一条浅色饰带；无桅船的舱房加两扇小亮窗 + 一盏小灯（加法光晕 Sprite）。

## 6. 验收
- 同机位前后对比：街道近景、广场全景、教堂正面、运河船只各一张。
- 控制台 0 错误；帧率不低于 0f 后的 90%；`renderer.info.render.calls` 增加不超过 10。
