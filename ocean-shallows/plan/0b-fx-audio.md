# 0b-4 特效 / 音频

## 12-fx.js

- **粒子系统**：一个 `Points`（容量 1500，质量最低档 600），用自定义 shader，属性有 pos(xyz)、vel、life、size、kind。
  kind：0 = 水滴（白色、带高光）、1 = 泥沙（褐色、软边，水下）、2 = 雨点（短线条感）、3 = 荧光火花。
  CPU 每帧更新：重力 -9.8（只对空中的水滴和雨），水下粒子受阻力和洋流影响；水滴落到 z ≤ 0 时 `sim.drop(小)` 后消失。
  分两层渲染：水下粒子画进 underRT，空中粒子画到最终画面之上。
- `O.fx.splash(x, y, size)`：
  - sim：中心大扰动（r = 0.3·size，amp = 0.6·size），外圈再加 3 个随机小扰动；
  - 水滴：15–40 颗，向上和向外的冠状速度；
  - 泡沫：在合成 shader 中通过 `uFoamSpots[8]`（x, y, 出现时间, 大小）画出向外扩散的环形泡沫，持续 1.5 秒；
  - bio：注入大块荧光（只在月夜有效）；
  - 音效：`O.audio.splash(size)`。
- `O.fx.drip(x, y, z)`：一颗水滴，从 z 高度落下。
- `O.fx.silt(x, y)`：40 颗泥沙粒子，在水下半球形散开、缓慢沉降，持续 3 秒；同时在海床层画一团暗色晕圈。
- **下雨**（开关，R）：每帧随机 6–12 个雨点位置做 sim 微小扰动（amp 0.02）；屏幕上叠加斜向雨丝（CSS 无法实现时，就用 kind 2 粒子）；
  画面整体变暗 15%（通过 uniform `uRain` 控制，平滑过渡）；音效加入白噪声雨声。
- **漩涡**（开关，W）：位置 `O.vortex = {x, y, on, strength}`；
  - 在 sim 中，每帧沿环形注入切向的小扰动（8 个点绕中心旋转），形成螺旋波纹；
  - 合成 shader 中用 `uVortex` 让折射坐标扭转（旋转角 ∝ exp(-r²)），中心加暗色和白色螺旋泡沫；
  - 对水母和粒子施加旋转力：切向 `1.2/(r+0.3)`，向心 0.3；鳐鱼和鲨鱼只受很弱的影响；
  - 界面：一个圆形拖动手柄（DOM 元素，带旋转动画），拖动时更新位置。
- **平静**（C）：sim 全部清零（用一个清零 pass），雨和漩涡关闭，长浪振幅在 3 秒内降到 0.2；再按一次恢复。
- **清空海面**：`O.clearAll()` + 播放一个柔和的下行提示音。

## 13-audio.js — WebAudio（首次用户交互时创建 AudioContext；声音默认关闭）

- 主输出链：`master gain → DynamicsCompressor → destination`。
- **海浪**：粉噪声 buffer（循环播放）→ 低通（截止 400–1400 Hz，随 swash 变化）→ gain。
  gain 包络：`0.15 + 0.5 * O.swash()^1.5`，每帧用 `setTargetAtTime` 平滑跟随；
  另一路带通噪声（2–4 kHz），只在 swash 回落阶段增大，模拟回流的嘶嘶声。
- **水花**：噪声加短包络（攻击 5 ms、衰减 0.25–0.6 秒），带通频率 900–2500 Hz 随 size 变化；
  再叠一个正弦「咕咚」声（180→60 Hz 快速下滑，持续 0.15 秒）。
- **提示音**（清脆）：两个正弦加三角波，音高 E6 / B6，衰减 0.4 秒，混一点简单延迟。
  类型：spawn（上行两音）、deny（下行两音）、ui（单音）、scene（三音琶音）。
- **雨**：高通白噪声，gain 0.12。**漩涡**：低频噪声，带通约 200 Hz，缓慢调制。
- **场景**：黄昏时整体低通更低；月夜时海浪音量 ×0.7，并加入极轻的高频「叮」声（与荧光爆发同步）。
- M 键或按钮切换静音：`master.gain` 在 0.3 秒内渐变；按钮图标同步更新。
