# 0b-3 生物

## 08-creature-base.js

```
class Creature {
  type, kind('ray'|'shark'|'jelly'), size, pos:Vector3, vel:Vector2, heading, bank, pitch, roll
  state: 'swim'|'rest'|'flee'|'jump'|'thrown'|'held'|'drop'
  speed, targetSpeed, wanderPhase, stateT
  update(dt)  -> 由子类实现 steer() 和 animate()
}
```
- **转向**（swim）：`desired = 漫游方向（噪声驱动 heading）`，再叠加几个力：
  - 避岸：采样前方 `pos + dir*1.2` 处的 `depthAt`，若 < `minDepth(type)`，就朝 `∇depth` 方向转；
  - 避边：离屏幕边缘 < 0.8 时向中心转；
  - 分离：与其他生物距离 < (r1+r2)*1.2 时互相推开；
  - 鲨鱼排斥：鳐鱼与鲨鱼距离 < 2.2 时远离（力度弱）。
  转向角速度有上限；`bank = clamp(-dHeading/dt * k, ±0.6)`，做平滑处理。
- **深度**：游动高度 `z = -depth*frac`，frac 依物种不同；靠近水面（z > -0.25）时每 0.08 秒在 sim 中 `drop(r=0.15·size, amp 小)`，形成尾迹；荧光同理注入 `bio`。
- **触碰**：`hit(pointer)` → flee：`heading = 远离指针方向 ± 随机`，速度 ×2.5，持续 1.5 秒；同时触发 sim 和 bio 注入。
- **抛入**（thrown）：起点 = 卡片在屏幕上的世界坐标，z = 2；终点 = 随机水面点（必须是水且 depth > 0.8）。
  飞行时长 0.9 秒，`z = 2 + 3*τ - 5*τ²` 的抛物线形状（插值到终点 z=0），身体沿速度方向翻滚。
  入水时调用 `O.fx.splash(x, y, size)`，然后进入 drop 状态（0.6 秒内下沉到游动深度）。
- **拖动**（held）：z = 1.5，跟随指针（加阻尼）；水母触手垂下并滴水（每 0.15 秒向 fx 加一个水滴）。松手后进入 drop：若位置在沙滩，就移到最近的水点。
- **跃出**（ray 中的 manta 和 eagle）：每只生物每 25–60 秒有一次机会（需满足 depth > 1.2 且处于 swim 状态）：
  先加速上浮 → 出水 `splash(小)` → 空中 1.1 秒（抛物线，绕身体纵轴翻转 1 圈）→ 落水 `splash(大)`。
- **影子**：在 underRT 中画 `ShadowSprite`（径向渐变的透明圆，按物种拉伸成椭圆），
  位置 = `pos.xy + (-sunDir.xy/sunDir.z) * (pos.z + depth)`，大小随离海床高度增大而变大，透明度随之变淡。
  空中的生物把影子画在水面合成之上（暗色叠加）。
- **管理**：`O.creatures` 数组；`O.spawn` 检查上限 48，超过时 `O.audio.chime('deny')`，并提示「海里太挤啦」。
  `O.clearAll()`：所有生物淡出并下沉，0.8 秒后移除。计数器文字：只显示数量大于 0 的类别（量词：鳐鱼「只」、水母「只」、鲨鱼「条」）。
- 初始生成：2 只蝠鲼、1 只鹞鲼、1 只魟、3 只海月水母、2 只金黄水母、2 条鲨鱼（随机分布在合适的水深）。

## 09-rays.js — 鳐鱼（3 种，各一个 InstancedMesh，maxCount 16）

- **几何**：在 (u 翼展 -1..1, v 体长 -1..1) 网格上（细分 24×16），轮廓：
  - 蝠鲼和鹞鲼：菱形翼，`halfSpan(v) = 翼形曲线`，翼尖后掠；魟：近圆形圆盘。
  - 背、腹两层：背面 z = `+thick*(1-u²)(1-v²)`，腹面取负，边缘缝合；材质用 `side:Double`，分别贴背面和腹面纹理（通过 `gl_FrontFacing` 选择）。
  - 尾巴：细长三角带，并入同一几何，用 attribute `aTail=1` 标记，由 shader 摆动。
  - 蝠鲼：头前方两片头鳍（小卷片）。
- **顶点 shader**（每个实例的 attribute：`aPhase`、`aFlap`（扇动幅度）、`aMode`（0 = 扇动，1 = 边缘波动）、`aBank`）：
  - 扇动：`z += aFlap * sin(t*ω + aPhase - |u|*1.2) * pow(|u|, 1.6)`；
  - 边缘波动：`z += aFlap * sin(v*8 - t*ω + aPhase) * smoothstep(0.6, 1, r)`；
  - 尾巴：`x += sin(t*2 + v*4)*0.05*tailT`；
  - 侧倾：绕体轴旋转 aBank（在 instanceMatrix 里实现）。
- **纹理**（CanvasTexture 256×256，背面和腹面各一张）：
  - 蝠鲼：背面近黑，两肩各有一块白色 V 形斑；腹面白色，带不规则深色斑点和深色鳍缘。
  - 鹞鲼：背面深蓝黑，布满白色点和环纹；腹面白色；尾巴很长（3 倍体长），细鞭状。
  - 蓝点魟：背面黄褐色带电光蓝斑点，双眼后方有喷水孔（深色小点）；尾巴有蓝白相间条纹。
- **光照**：简单的 Lambert（sunDir）加环境光，水下颜色略带蓝绿。
- **魟鱼休息**：在 depth < 2.5 的沙地上随机进入 rest（停 8–20 秒，z = -depth + 0.05，只有边缘轻微波动）。
  受惊离开 rest 时调用 `O.fx.silt(x, y)`，扬起一团泥沙。

## 10-shark.js — 黑鳍礁鲨（Mesh，体长 1.6）

- 身体：沿 x 轴的纺锤形，截面是椭圆，半径曲线 `r(s) = 0.18 * sin(π·s^0.7)`（s 为 0–1，从头到尾）；
  背部灰褐色 #8a8070，腹部白色（按法线 z 混合）。
- 鳍：第一背鳍（三角，尖端黑色）、胸鳍（水平、稳定、尖端黑色）、尾鳍（新月形不对称，下叶尖端黑色）、第二背鳍。黑尖用顶点颜色实现。
- S 形摆动：`y += A(s) * sin(k*s - ωt)`，`A(s) = 0.02 + 0.12*s²`，ω 随速度变化；胸鳍不参与摆动。
- 行为：速度是鳐鱼的 1.8 倍；偏好在 depth 0.5–1.5 的区域沿岸巡游（转向力指向 `∇depth` 的切线方向）。
  depth < 0.9 时游动深度贴近水面，背鳍出水：每帧在背鳍处 `drop`，形成 V 形尾迹，并在水上层画一个小背鳍尖。
- 结群：生成时有 40% 概率带 1–2 条同伴；同伴有跟随力（领头鲨身后侧方 1.2 的位置）。
- 触碰：瞬时速度 ×3，急转 90°–150°，并伴随大扰动。

## 11-jelly.js — 水母

- **钟体**：`LatheGeometry`（轮廓为半椭圆加外翻边缘）。
  shader：菲涅耳 `α = 0.15 + 0.6*pow(1 - |n·v|, 2)`，加法与透明混合；`depthWrite=false`。
- **脉动**：周期 T = 1.6–2.2 秒。收缩期占 30%（快）：钟体半径 ×0.78、高度 ×1.15；舒张期占 70%（慢）恢复。
  推进力只在收缩时作用：`vel += axis * impulse`，axis 是钟体的朝向（俯视时近似为水平方向的 heading）。
- **漂移**：`vel += current(p, t)`（低频旋度噪声的流场）+ 漩涡力（切向 + 向心）；有阻尼。
- **月夜**：钟体自发光 `emissive = 青色 * (0.3 + 0.3*脉动)`，并持续向 bio 注入微弱荧光。
- **海月水母**（直径 0.7）：钟体近乎无色透明；4 个粉色马蹄形生殖腺（4 个环形扁片，在钟体内顶部）；
  放射管（16 条细线，用 LineSegments）；边缘一圈细短触手（48 条短丝带）。
- **金黄水母**（直径 0.8）：琥珀色钟体，16 条锈红色放射条纹（画在纹理里）；
  8 条长拖曳触手（长 2.5）+ 4 条带褶边的奶油色口腕（长 1.5，丝带更宽，边缘用噪声做褶皱的透明度）。
- **丝带**（触手和口腕）：每条是一根 Verlet 节点链（12–20 个节点），根部固定在钟体边缘；
  每帧施加向后的阻力（与速度反向）和重力（-z，只在 held 或速度很低时明显），然后做长度约束迭代 2 次。
  渲染：所有丝带合并成一个动态 BufferGeometry，每个节点生成 2 个顶点，沿「切线 × 视线方向」展开（朝向相机），宽度从根到梢逐渐变细。
- **held 状态**：z = 1.5，触手笔直垂下；每 0.15 秒从触手末端生成一个水滴粒子（`O.fx.drip`）。
