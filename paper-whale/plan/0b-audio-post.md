# 0b · 音频与后期（audio/synth.py / post.sh）

## 输入

- `build/events.json`：每帧的纸群平均速度 `speed`（m/s）和聚形进度 `formed`（0→1）。
- 镜头切点：帧 73 = 3.0 s。全片 10.0 s，48 kHz 立体声。

## 声音设计（全部由代码合成，不用采样）

1. **房间底噪**：粉红噪声，经 200 Hz 低通，−48 dBFS，再加 0.1 Hz 的缓慢起伏。代表深夜大厅的空气。
2. **镜头 1 · 掀页**：
   - 0.6–1.6 s：「纸被风掀起」= 带通噪声（中心 2.5→4 kHz，Q 1.2），包络跟着 α(t) 的速度走，加入 30–60 Hz 的随机颗粒调制（纸纤维的沙沙声）。
   - 1.6–2.6 s：纸页飞走 = 同一个声源，音量渐弱，声像从中间平移到右侧。
3. **镜头 2 · 纸群**：
   - 主体：几十层「纸沙」叠加。每层是带通噪声（中心 1.5–6 kHz 随机），
     用随机的 8–25 Hz 颗粒包络调制，模拟很多纸页各自扑动。
     总响度 ∝ smooth(speed)，声像随纸群重心的 x 坐标平移。
   - J-cut：纸群声在切点前 0.25 s 先淡入。
   - 聚形「呼」声：t ∈ [3.6, 5.8] 加一层低频噪声（150–600 Hz）的上扬扫频，体现鲸被「吸」成形。
   - 成形后：纸沙声变成稀疏、温柔的颤动（颗粒密度下降，高频减少）。
4. **钢琴**（加法合成）：
   - 音色：每个音 12 个泛音，带非谐性 B = 0.0004，每个泛音单独做指数衰减（高泛音衰减更快），
     加一个 4 ms 的击弦噪声瞬态，以及 2 根弦 ±0.6 音分的失谐（产生拍频）。
   - 谱子（D 大调，慢板，♩= 60）：
     - 0.4 s：D4 + A4（轻），2.0 s：F#4，
     - 3.0 s（切点）：低音 D2 + D3 八度，
     - 4.5 s：A4，5.5 s：B4，6.5 s：C#5（纸流盘旋时一级级上行），
     - 7.6 s（鲸成形）：D 大和弦 D3 F#3 A3 D4 F#4 + 高音 A5，
     - 9.0 s：D5 余音。
   - 混响：用合成的冲激响应卷积（指数衰减的噪声，RT60 约 3.2 s，左右声道去相关）。
5. **混音**：钢琴 −14 dBFS，纸声峰值 −16 dBFS，母线软限幅（tanh），8.6 s 后整体淡出。
   输出 `build/audio.wav`，48 kHz / 16 bit / 立体声。

## 后期（post.sh，ffmpeg）

1. 帧序列 `build/frames/f_%04d.png`（1920×816，16 位 PNG）→ 视频 24 fps。
2. 调色链：
   - `eq`：对比度 1.05，饱和度 0.92，gamma 0.98；
   - `colorbalance`：暗部偏青蓝（bs +0.04，rs −0.02），高光偏暖（rh +0.03，bh −0.02）；
   - `vignette`：PI/5；
   - 胶片颗粒：`noise=alls=5:allf=t`；
   - 镜头 1 已经偏暖，不单独处理（同一条调色链，保证两个镜头统一）。
3. 黑边：`pad=1920:1080:0:132`（2.35:1 letterbox）。
4. 淡入：0–0.4 s 从黑场进；淡出：9.2–10 s 到黑场。
5. 编码：libx264 crf 16、preset slow、yuv420p、faststart；AAC 256k。输出 `output.mp4`。
