# 00 · 总体架构（paper-whale）

10 秒验证短片：深夜图书馆，一页纸飞起，随后一万多页纸涌入、盘旋、聚成一头鲸。
全部由 Python 驱动 Blender 5.2 生成，不用视频模型。

## 规格

- 24fps，全局帧 1–240（10 s）。渲染 1920×816（2.35:1），后期 pad 成 1920×1080 黑边。
- 单位为米，Z 轴朝上。色彩管理用 AgX。
- 镜头 1：帧 1–72（3 s），**Cycles**（Metal GPU，自适应采样 + 降噪）。
- 镜头 2：帧 73–240（7 s），**EEVEE**（光追 + 体积阴影 + 运动模糊）。
- 预览：两个镜头都用 EEVEE，`--pct 50`（960×408）。

## 世界布局（固定坐标，各模块共用，写在 common.py）

- 大厅：X ∈ [-7, 7]，Y ∈ [-4, 32]，Z ∈ [0, 12]。
- 左墙（x = -7）开 4 扇高拱窗，中心 y = 4, 11, 18, 25，宽 2.4 m，窗台高 z = 2.5，窗顶高 z = 9（半圆拱）。
  窗格用细框条做；窗外放一块冷蓝色的自发光「夜空」板。
- 右墙（x = +7）和尽头墙（y = 32）：通高书架，Z ∈ [0, 8]，书本用 NumPy 批量生成盒子，合并成一个 mesh。
- 阅览长桌：中心 x = 1.6，Y ∈ [2, 16]，桌面高 0.76，两侧放椅子。
- 摊开的书在 (1.6, 7.0, 0.76)；油灯在 (1.75, 7.9, 0.76)。
- 月光：Sun 灯，从左上方 (-X, 略偏 -Y) 斜射入窗，仰角约 35°，色温冷蓝。
- 体积：覆盖整个大厅的立方体，Principled Volume 密度约 0.012，anisotropy 0.55。
- 鲸成形位置：中心 (0.0, 17.0, 5.2)，体长约 10 m，身体轴沿 X（侧面朝向镜头，最容易认），头朝 +X。

| props.py | 摊开的书（页堆）、油灯（玻璃罩+火焰+点光）、桌上散书 | 0b-scene.md |
| lights.py | 月光、夜空板、体积立方体、油灯光、世界、渲染设置（引擎切换） | 0b-scene.md |
| whale.py | 鲸的目标点云 + 每个点的朝向（参数化身体 + 鳍 + 尾鳍） | 0b-swarm.md |
| swarm.py | NumPy 纸群模拟 → 每帧顶点 → PC2 缓存 + Mesh Cache 修改器 | 0b-swarm.md |
| hero_page.py | 镜头 1 那一页纸：掀起、卷曲、飞出（PC2） | 0b-shots.md |
| cameras.py | 两台摄像机、运镜、手持抖动、景深、标记点绑定切换 | 0b-shots.md |

脚本：

- `tools/make_textures.py`：用 Blender 文字对象正交渲染出书页文字贴图 → `build/tex/page_*.png`（只需跑一次）。
- `build_scene.py`：组装场景 → `build/paper_whale.blend` + `build/events.json`（纸群速度包络，给音频用）。
- `stills.py`：按帧号渲染静帧（参数 `--engine --pct --samples`）→ `build/stills/`。
- `check.sh`：重建场景并渲染若干检查帧。
- `render.sh`：按帧范围和引擎渲染序列 → `build/frames/f_####.png`，可断点续渲。
- `audio/synth.py`：合成纸张声 + 钢琴 → `build/audio.wav`（用 Blender 自带 Python 跑，含 numpy）。
- `post.sh`：ffmpeg 调色、颗粒、暗角、黑边、淡入淡出、混音 → `output.mp4`。

## 动画数据流

1. 所有动画都是「时间 → 顶点」的纯函数，在 NumPy 里先算好每一帧。
2. 纸群和主角页写成 PC2 点缓存（`build/cache/*.pc2`），用 Mesh Cache 修改器回放。
   Blender 会在子帧之间线性插值，所以 Cycles 和 EEVEE 的形变运动模糊都能用。
3. 摄像机用关键帧（每帧都打一个，手持噪声直接烘进去）。
4. 拓扑恒定：每页纸 6 个顶点（3×2，沿长边中线可以折弯），纸群共 16000 页，即 96k 顶点。

## 纸群时间线（镜头 2，局部时间 t = (帧 − 73) / 24，0–7 s）

- 0.0–2.2 s「涌入」：纸流从左后方高处的窗口方向沿样条曲线涌进来，像一条河；每页纸在流管截面上有固定槽位。
- 2.2–4.0 s「盘旋」：纸流在大厅中央甩成一个正对镜头的竖直螺旋回环，逐渐收紧。
- 4.0–5.8 s「聚形」：每页纸飞向自己在鲸身上的目标点；从头到尾依次到位，所以能看到鲸被「画」出来。
- 5.8–7.0 s「游动」：鲸成形后尾鳍缓慢摆动，表面纸页轻微颤动，少量散页从尾部飘落。
- 全程：每页纸有自己的翻滚和折弯（相位随机），速度越快翻得越剧烈。

## 镜头

- 镜头 1：微距感（焦距 85 mm，光圈 f/1.8），贴着桌面低机位看书页，背景是油灯焦外光斑。
  手持微抖，慢推。第 0.6 s 起一页纸掀起、卷曲，第 2.2 s 被风带出画面右上角。
- 镜头 2：24 mm，机位在大厅前端 (−2.5, −2.5, 1.7)，看向 +Y 并略微仰拍。
  7 秒内缓推加轻微升起（摇臂感），光圈 f/4，焦点跟着纸群重心走。

## 风格

- 冷蓝月光 + 一点暖橙油灯，大面积暗部，高光克制。
- 后期：轻微青绿暗部 / 暖高光分离，胶片颗粒，暗角，2.35:1 黑边。

## 验收（检查点）

1. 静帧：f30（镜头 1）、f110（涌入）、f160（盘旋）、f225（鲸）。
2. 预览：EEVEE 960×408 全 240 帧 → `build/preview.mp4`。
3. 成片：`output.mp4`，同时记录两个镜头的单帧平均耗时。
