# 0b · 纸群与鲸（swarm.py / whale.py）

## 数据规模

- N = 16000 页（其中 5% 是「散页」，始终不入队）。每页 6 个顶点（沿长边 3 行 × 沿宽边 2 列），共 96k 顶点。
- 页面大小：宽 0.13 × 长 0.19 m。UV：贴图集是 2×2 的四张文字页，每页随机取一个象限。
- 缓存帧：全局帧 72–241（比镜头 2 多出前后各 1 帧，留给运动模糊），PC2 起始帧 = 72，约 200 MB。
- 局部时间 t = (frame − 73) / 24。镜头 1 期间纸群在窗外（不可见），不需要隐藏。

## 每页的固定属性（rng 种子 7，可复现）

- `u`：在队伍里的顺序，0 是排头，1 是排尾。
- `r, θ`：在流管截面上的槽位，r = sqrt(U) 均匀分布在圆盘里。
- `phase, ω_tumble ∈ [2, 6] rad/s, axis`：翻滚相位、角速度、随机轴。
- `ω_flap ∈ [5, 9]`：折弯频率；`noise` 用的 3 组随机相位。
- `k`：在鲸身上的目标次序（0 是鲸头，1 是尾鳍）。

## 路径 C(s)：入口贝塞尔曲线 + 竖直螺旋回环（实测后修订）

- 水平圆环从低机位看只是一个扁平的光团，所以改成**正对镜头、略微后仰 20° 的竖直回环**。
- 回环：中心 Cv = (0.5, 15, 6)，R0 = 4；回环所在平面由 E1（「下」方向，后仰 20°）和 E2 = +X 张成。
  入口点 J = Cv + R0·E1（回环底部），J 处切线是 +X。纸流从窗口俯冲下来，从底部向右切入，逆时针绕行。
- 入口：三次贝塞尔，P0 = (−9, 26.5, 7)，P1 = (−6, 24, 6.8)，P2 = J + (−5, 0.9, 0.2)，P3 = J。
  先密采样 400 点，再按弧长重参数化（`np.interp`）。s < 0 时沿 P0 的切线向窗外延伸。
- 螺旋收紧：半径 = lerp(R0, R(t), smooth((s − LB)/8))，R(t) 在 t ∈ [2.2, 4.0] 内从 4.0 收到 2.8。
  因为半径是随弧长渐变的，衔接点始终连续，不会瞬移。散页的半径另外再乘 1.4。
- 页 i 的弧长：s_i(t) = v·(t + 0.3 − 3.0·u_i)，v = 6 m/s（排头在 t = −0.3 时刚好进窗）。
- 局部坐标系：N = normalize(T × up)，B = N × T。
- 截面半径：R_tube = (0.6 + 0.6·入环程度) × sqrt(sin(π·u)) + 0.15。
- 流动位置：S_i(t) = C(s) + R_tube·r·(cos θ·N + sin θ·B) + 噪声。
  噪声 = 每页自身的 0.2·sin(ω t + φ)（三个轴各一组）
  + 群体波动 Σ_j 0.5·sin(k_j·p + w_j t)·d_j（3 个分量），形成椋鸟群那样的波浪。

## 鲸（whale.py）

`whale_targets(n, rng) → dict(pos0, normal, tangent, s, part)`，在鲸的局部坐标里：x 是身体轴（头在 +x），z 朝上。

- 体长 L = 9 m。身体半径（s 是从头到尾的 0→1）：
  r(s) = 1.3 · f(s) / 0.406，f(s) = s^0.4 · (1 − s)^1.2。截面是椭圆：侧向 1.0·r，竖向 0.85·r。
  再让腹部略平：z < 0 的一侧乘 0.8。
- 胸鳍（座头鲸式长胸鳍，是辨识度最关键的部分）：两只，根部在 s = 0.3、z = −0.4r，
  向外下方伸出 3.0 m，后掠 35°，宽从 0.55 m 逐渐收到 0.1 m，扁平。
- 背鳍：s = 0.68，小三角形，高 0.35 m。
- 尾鳍：在 s = 1 处，水平的两片，翼展 ±1.7 m，弦长 0.9 m，后缘呈 M 形缺口。
- 采样数量：身体约 78%（按周长 ∝ r 加权采样 s，角度均匀），胸鳍 10%，尾鳍 10%，背鳍 2%。
  每个点沿法向随机偏移 ±0.06 m，让纸页叠出鳞片般的厚度。
- 每页在鲸身上的朝向：法向 = 表面法向；长边大致沿身体切线，带 ±25° 随机扭转。
- 目标次序：k = s + 0.1·rand（胸鳍取根部的 s，尾鳍取 1）。

### 鲸的世界变换与游动（时间 t 的函数）

- 中心 (0.0, 17.0, 5.2)；偏航 −25°（头朝 +X 并略向镜头）；抬头俯仰 +8°。
- 身体波动：中心线 z 偏移 = A(t)·s²·sin(2.2t − 3.5s)，A 在 t ∈ [4.5, 6] 内从 0.15 增大到 0.35，作用在身体和尾鳍上。
- 整体向头的方向漂移，速度 0.25 m/s。
- 表面颤动：每页加 0.03 m 的法向抖动，并绕法向做 ±8° 的小幅摆动。

## 聚形

- 页 i 的开始时间：tc_i = 3.6 + 1.2·k_i + 0.2·rand；时长 D = 1.1 s；进度 e = smootherstep((t − tc)/D)。
- 位置：P = lerp(S_i(t), W_i(t), e) + sin(π e)·arc_i，arc_i = 1.2·rand·(up + 圆环切向)，
  这样纸页是沿弧线飞过去的，不走直线。
- 朝向：q = slerp(q_tumble(t), q_target(t), e)。翻滚 q_tumble = axis-angle(axis_i, phase + ω_tumble·t)。
- 折弯幅度：0.035·sin(ω_flap t + φ)·(1 − 0.85e)（停在鲸身上后几乎不再折弯）。
- 散页（5%）：e 恒为 0，圆环半径放大 1.4 倍，并以 0.15 m/s 缓慢下沉。

## 输出

- `swarm.build(cache_dir)`：
  1. 生成纸群 mesh（第 0 帧的顶点、UV、材质），用 Mesh Cache 修改器挂上 PC2；
  2. 逐帧计算顶点（N×6×3，float32）并写入 PC2；
  3. 返回每帧统计，给 events.json：平均速度（纸声包络）、当帧刚到位的页数（聚形「沙」声）。
- 四元数工具（向量化）：axis_angle、from_matrix、slerp、to_matrix，放在 swarm.py 顶部。
