# 0b · 镜头（hero_page.py / cameras.py）

## 镜头 1 · 帧 1–72，t1 = (frame − 1) / 24 ∈ [0, 3)

### 构图

- 书：书脊沿 +Y，中心 (1.6, 7.0, 0.76)；右页范围 x ∈ [1.6, 1.75]，y ∈ [6.89, 7.11]。
- 油灯：(1.75, 7.9, 0.76)，在书的后方，形成焦外光斑。
- 摄像机：85 mm，f/1.8，机位约 (1.82, 6.48, 0.83)，看向 (1.66, 7.05, 0.79)：
  从书的右前角低机位看过去，能同时看到右页、页堆侧面和背后的灯。最终位置在静帧检查时微调。
- 景深：focus_object 是一个空物体，0–1.3 s 在右页外沿，之后跟主角页的重心。
- 运镜：3 秒内向前缓推 4 cm，叠加手持噪声（位置 ±1.5 mm，旋转 ±0.15°，用 0.3–1.2 Hz 的正弦叠加，不用随机数）。

### 主角页（hero_page.py）

- 网格：16（沿宽，从书脊到外沿）× 10（沿长），宽 0.15、长 0.22，双面，用文字贴图。
- 形状用「沿宽度积分角度」得到：θ(w) = α(t) + curl(t)·w + twist(t)·(y_n − 0.5)·w，
  其中 w ∈ [0, 1] 从书脊算起；剖面点 = spine + ∫(cos θ, 0, sin θ)·dw·0.15，长度方向沿 Y。
  t = 0 时 α = 0、curl 很小，并让页面贴合右页块的弧面（外沿抬高 1 cm）。
- 时间线：
  - 0–0.6 s：静止；外沿角有轻微呼吸，±2 mm。
  - 0.6–1.6 s：被风掀起，α 从 0 升到 75°，curl 从 0.3 升到 1.4（纸页向内卷），twist 0.5（下角先抬）。
  - 1.6–3.0 s：脱离书脊。整页的刚体变换 = 平移 v0·τ + 0.5·a·τ²（v0 = (0.05, 0.02, 0.12)，a = (0.35, 0.10, 0.25)）
    + 绕 Y 轴持续滚转 + 绕 Z 的慢偏航；形状继续以 4 Hz 小幅抖动。约 2.6 s 从画面右上角出画。
- 用 PC2 输出 160 个顶点 × 74 帧（帧 0–73）。
- 返回 `centroid(frame)`，给对焦空物体用。

## 镜头 2 · 帧 73–240，t = (frame − 73) / 24 ∈ [0, 7)

- 摄像机：24 mm，f/4。
  - 位置：(−2.5, −2.5, 1.7) → (−1.4, 2.5, 2.5)，用 easeInOut 的三次曲线插值（摇臂式缓推加升起）。
  - 朝向：看向目标点 L(t)。L 从 (−3.5, 18, 6.2)（纸流入口）平滑过渡到纸群重心，
    t ≥ 4.5 时锁定在鲸中心。过渡用阻尼（一阶低通，τ = 0.6 s），模仿摄像师跟拍时的滞后。
  - 手持噪声比镜头 1 更小（摇臂很稳）：旋转 ±0.05°。
  - 对焦距离 = 摄像机到 L(t) 的距离（逐帧打关键帧）。
- 镜头 2 的油灯：桌上同一盏灯在远处，作为一个暖色的小点保留。

## 切换与时间

- 两台摄像机 `Cam1`、`Cam2`。时间轴标记 F_01 绑定 Cam1，F_73 绑定 Cam2。
- 所有摄像机动画都逐帧打关键帧，插值方式为 LINEAR。
- 帧 72→73 是硬切。纸声在切点前 0.2 s 提前进入（J-cut，由音频负责）。

## 检查帧

- f30：主角页正在掀起（镜头 1，看景深、纸张透光、灯的焦外光斑）。
- f110：纸流从窗口涌入，光柱里能看到纸流。
- f160：漩涡。
- f225：鲸成形。
